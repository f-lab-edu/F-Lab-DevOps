# AI 운영 조사 로컬 사이트

`index.html`은 A0 → A1 → A2 구현 현황의 요약 페이지다. 왼쪽 메뉴에서 `a0.html`, `a1.html`, `a2.html`로 이동하면 각 단계의 처리 흐름을 볼 수 있다. **프로젝트 자료** 메뉴의 `structure.html`은 현재 AI 관련 폴더·하위 파일과 역할을, `cli.html`은 A3의 세 가지 CLI 명령어·필수 옵션·실행 예시를 정리한다. A0·A1 작업 리마인드는 구현 방식과 이유를 짧게 보여주며, 단계·파일·검증 항목·합성 사례를 선택하면 오른쪽 설명 패널에서 근거를 확인할 수 있다. CSS와 JavaScript는 `assets/`에 분리했으며 외부 서비스나 빌드 도구가 필요 없다.

저장소 루트에서 로컬 HTTP로 열려면 다음처럼 실행한다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

그다음 `http://127.0.0.1:8000/ai-ops/site/`를 연다. 원본 코드·문서 링크까지 사용하려면 저장소 루트를 서버 시작 위치로 유지한다. 단순 열람은 `index.html` 파일을 직접 열어도 된다.

이 사이트의 단계별 흐름 페이지는 A0~A2까지 설명한다. 폴더 구조 페이지에는 현재 작업 파일인 A3 로컬 구현도 포함하지만 A3 단계별 그림은 아직 없다. 실클러스터 조사·AI 진단·조치 실행은 아직 연결되지 않았다. 새 단계는 별도 페이지와 왼쪽 메뉴에 추가하고, 상세 설명은 `assets/*-data.js` 파일로 관리한다. 폴더 구조 목록은 파일 변경 시 수동으로 갱신한다.
