2026-09-30 기준 · 로컬 파일 구조

AI 관련 자료는 구현 코드·검증 자료인 ai-ops/, 기획·작업 순서 문서인 실습 가이드 문서 모음/AI/, 자동 검사인 .github/workflows/ai-ops-ci.yml에 나뉘어 있습니다. 파일 이름을 누르면 원본을 엽니다.

A3 파일도 현재 작업 디렉터리 기준으로 포함했습니다. 단계별 시각화 페이지는 아직 A2까지이며, 실제 AI 모델 연결·실클러스터 수집·조치 실행은 이 파일 구조에 포함된 구현 범위가 아닙니다.

AI 패키지 변경을 자동으로 검사하는 GitHub Actions 설정입니다.

  • ai-ops-ci.yml의존성 설치와 계약·증거·로컬 조사 시험을 실행하는 워크플로.

표시 범위는 현재 작업 파일 중 사람이 관리하는 AI 관련 자료입니다. build/, *.egg-info/, __pycache__/, .DS_Store처럼 자동 생성되는 항목은 목록에서 제외했습니다. 이 목록은 파일 변경에 따라 수동으로 갱신합니다.
